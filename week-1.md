# Week 1 Write-Up

I chose to build an app for the league I play in, the Wilson Park Monday night league. Players and coaches need a clean place to track their stats, and the league's current stats page was not clean. It is sloppy, hard to read and not clean. 

What surprised me most about Claude Code was that it can run my Git commands and push my work to GitHub once I approve them, so everything stays connected without me doing each step by hand.

One thing that went wrong: the Home page background was very plain, so I asked Claude Code to add graffiti. It ended up looking hideous. Because I had not committed the change yet, I was able to cancel it with one command, git restore index.html, which was very easy.

I gave the directions and reviewed each change, and Claude Code wrote the code.

Live app: https://wilson-park-basketball-stats.vercel.app
